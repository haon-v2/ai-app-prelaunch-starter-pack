# AI App Prelaunch Checklist

A compact final pass for apps built with Codex, ChatGPT, Claude, or another coding agent.

## Core experience

- [ ] A new user can complete the main task from a fresh launch.
- [ ] Every button, menu item, and keyboard shortcut gives visible feedback.
- [ ] Empty, loading, offline, permission-denied, and error states are understandable.
- [ ] The app preserves user work after closing and reopening when promised.
- [ ] Destructive actions have confirmation or a clear recovery path.

## Evidence

- [ ] Each promised feature has an observable acceptance check.
- [ ] Tests cover meaningful behavior rather than only implementation details.
- [ ] Known failures can be reproduced with exact steps.
- [ ] The final build was tested outside the development environment.
- [ ] Screenshots, recordings, or test results support the release decision.

## Privacy and security

- [ ] No credentials, tokens, personal data, or private URLs appear in the source, logs, prompts, screenshots, or download.
- [ ] Permissions and network access are limited to what the product needs.
- [ ] Data storage, deletion, export, and recovery match what users are told.
- [ ] Dependencies and bundled assets have acceptable licenses and known origins.

## Packaging

- [ ] The version matches across the app, release notes, metadata, and filenames.
- [ ] Installation and first launch work on a clean or representative device.
- [ ] Upgrade behavior is checked when replacing an earlier version.
- [ ] Setup steps, limitations, privacy behavior, and support contact are documented.
- [ ] The final downloadable artifact is the intended file and opens correctly.
